# Small Talk Coffee app

Обновлённый Expo / React Native проект в новой фирменной стилистике Small Talk Coffee.

## Запуск

```bash
npm install
npm start
```

Для web:

```bash
npm run web
```

## Что изменено

- новая красно-чёрно-белая графическая система интерфейса;
- убран старый glass/orange/aqua стиль;
- реальные карты: OpenStreetMap tiles на web и react-native-maps на iOS/Android;
- координаты трёх точек сверены по маршрутам 2ГИС, четвёртая привязана к зданию пр. Имама Шамиля, 1А;
- App.tsx остаётся небольшим, экраны и UI разнесены по файлам;
- продуктовые визуалы теперь генерируются интерфейсом, без тяжёлых PNG.
