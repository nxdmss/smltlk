Что сделано в этой версии:
- Поставлен брендовый логотип Small Talk в шапку.
- Знак логотипа используется как отдельный брендовый элемент.
- Палитра приведена ближе к брендбуку: оранжевый #FA4713, голубой #6BCBDD, белый, черный.
- Дизайн сделан более взрослым: тёмная база, резкие углы, более строгие карточки и кнопки.
- Мокапы напитков сохранены.
- Карта 2ГИС и точки сохранены.

Как ставить:
1. Распакуй содержимое архива в корень проекта C:\Users\umarc\smltlk
2. Если есть старые вложенные папки старых сборок, удали их.
3. Выполни npm install
4. Выполни npx tsc --noEmit
5. Выполни npm start
